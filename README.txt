النشر:
1) افتح مشروع Cloudflare الذي أنشأته.
2) استخدم خيار رفع الملفات/النشر المباشر للنسخة الجديدة.
3) ارفع محتويات هذا المجلد أو ملف ZIP.
4) لا تحذف مشروعك الحالي؛ استبدل الملفات في نفس المشروع حتى يبقى الرابط نفسه.

ملاحظة: هذه نسخة واجهة ومحتوى أولية قابلة للتطوير، ويمكن إضافة المزيد من الأذكار ومصادر كل ذكر لاحقًا.
